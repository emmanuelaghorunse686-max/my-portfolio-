About Me

How it all started

I started coding last year around May/June (WAEC period) by writing HTML on paper. I used my mom's Itel P55T phone in Ondo State to learn the basics — no laptop, no excuses.

When I moved to Lagos, I practiced on my sister's laptop using resources like Bro Code and Mosh. Today, I'm building full-stack apps and exploring cybersecurity.

When I'm not coding, I create funny, relatable videos on TikTok and YouTube — sharing the journey and making people laugh along the way. 😂🎬
